    python scripts/extract_warrants.py DSX --forms "8-A,424B5"

    python scripts/run_warrant_example.py

┌─────────────────────────────────────────────────────────────────────────┐
│ COMMAND LINE OPTIONS                                                    │
└─────────────────────────────────────────────────────────────────────────┘

  --from-file FILE        Read tickers from file (one per line)
  --from-date YYYY-MM-DD  Start date (default: 2020-01-01)
  --to-date YYYY-MM-DD    End date (default: today)
  --forms TYPE,TYPE       Form types (default: 8-A,424B2,424B3,424B5)
  --search "term"         Search term (default: "warrant")
  --output FILE.csv       Output file (default: auto-generated)
  --cache-dir DIR         Cache directory (default: output/warrant_cache)
  --skip-cached           Skip cached filings
  --max-results N         Max filings per ticker (default: 100)

    • has_ownership_limit, ownership_limit_pct
    • spac_related, warrant_class, notes
    • ... and ~50 more (empty columns dropped)

┌─────────────────────────────────────────────────────────────────────────┐
│ WHAT GETS EXTRACTED                                                     │
└─────────────────────────────────────────────────────────────────────────┘

  Core Terms:
    ✓ Strike price, expiration, conversion ratio
    ✓ Issue date, warrant type (Call/Put)
    ✓ Parent ticker, exchange, currency

  Call Triggers (CRITICAL):
    ✓ Trigger price (e.g., $18.00)
    ✓ Trading pattern (e.g., 20 out of 30 days)
    ✓ Redemption price (what issuer pays)
    ✓ Notice period

  Exercise & Settlement:
    ✓ Exercise type (American/European/Bermuda)
    ✓ Settlement type (Physical/Cash/Net Share)
    ✓ Cashless exercise terms

  Adjustments:
    ✓ Stock splits, dividends, mergers
    ✓ Anti-dilution provisions (Full Ratchet, Weighted Avg)

  Restrictions:
    ✓ Ownership limits (e.g., 4.99% blocker)
    ✓ Transfer restrictions
    ✓ Registration rights

  Classification:
    ✓ SPAC-related flag
    ✓ Warrant class (Public/Private/Founder)
    ✓ Free-form notes

┌─────────────────────────────────────────────────────────────────────────┐
│ SEC FILING TYPES                                                        │
└─────────────────────────────────────────────────────────────────────────┘

  8-A       → Primary warrant registration
  424B2/B5  → Prospectus supplements with terms
  6-K       → Foreign issuer filings (if needed)

  Search terms to try:
    • "warrant"
    • "warrant agreement"
    • "exercise price"
    • "redemption"

┌─────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                         │
└─────────────────────────────────────────────────────────────────────────┘

  No filings found?
    → Check ticker symbol is correct
    → Try broader date range (--from-date 2015-01-01)
    → Try just search term "warrant" without other filters

  Extraction errors?
    → Check cached filing: output/warrant_cache/{TICKER}/{TICKER}.*.txt
    → Verify filing contains warrant terms (not just mentions warrants)
    → Check Gemini API key in config.secrets.ini

  Empty results?
    → Some filings mention warrants but lack specifications
    → Try different form types (add 6-K for foreign companies)
    → Manually inspect filing_url from warrant_filings.csv
